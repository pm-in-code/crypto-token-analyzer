# 🌐 Настройка GitHub Pages

## ✅ **Деплой завершен!**

Ваш сайт готов к публикации. Теперь нужно активировать GitHub Pages:

## 🔧 **Шаги для активации:**

### **1. Перейдите в настройки репозитория:**
- Откройте: https://github.com/pm-in-code/crypto-token-analyzer
- Нажмите на вкладку **"Settings"** (вверху справа)

### **2. Найдите раздел "Pages":**
- В левом меню найдите **"Pages"**
- Или прокрутите вниз до раздела **"GitHub Pages"**

### **3. Настройте источник:**
- В разделе **"Source"** выберите **"Deploy from a branch"**
- В выпадающем списке **"Branch"** выберите **"gh-pages"**
- В поле **"Folder"** оставьте **"/ (root)"**
- Нажмите **"Save"**

### **4. Дождитесь активации:**
- GitHub покажет сообщение: **"Your site is published at https://pm-in-code.github.io/crypto-token-analyzer/"**
- Это может занять 2-5 минут

## 🌐 **Ваш сайт будет доступен по адресу:**
```
https://pm-in-code.github.io/crypto-token-analyzer/
```
