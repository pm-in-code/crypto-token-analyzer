## 🧪 **Быстрое тестирование:**

### **1. Откройте приложение:**
```
http://localhost:8000/public/
```

### **2. Протестируйте анализ:**
1. Введите токен: **"Bitcoin"** или **"ETH"**
2. Нажмите **"Scan"**
3. Дождитесь результата

### **3. Протестируйте премиум отчет:**
1. Нажмите **"Premium Report - $9.99"**
2. Должно открыться модальное окно оплаты
3. Введите тестовые данные:

**Тестовая карта:**
- **Номер:** `4242 4242 4242 4242`
- **Дата:** Любая будущая дата (например: `12/25`)
- **CVC:** Любые 3 цифры (например: `123`)
- **ZIP:** Любые 5 цифр (например: `12345`)

### **4. Ожидаемый результат:**
- ✅ Платеж пройдет успешно
- ✅ PDF скачается с именем `premium-crypto-analysis-...`
- ✅ В заголовке PDF будет "Premium Crypto Token Analysis Report"

## 🔍 **Проверка работы:**

### **Backend Health:**
```bash
curl http://localhost:3001/api/health
```
Должно показать: `"stripe_configured": true`

### **Stripe Payment Intent:**
```bash
curl -X POST http://localhost:3001/api/create-payment-intent \
  -H "Content-Type: application/json" \
  -d '{"amount": 999}'
```
Должно вернуть `clientSecret` и `publishableKey`
