# Crypto Token Analyzer

A React-based web application for analyzing cryptocurrency tokens with AI-powered insights and downloadable PDF reports.

## 🚀 Quick Deploy

### Option 1: GitHub Pages
1. Go to repository Settings → Pages
2. Select branch: `gh-pages`
3. Save and wait 2-5 minutes

### Option 2: Netlify (Recommended)
1. Go to [netlify.com](https://netlify.com)
2. Click "New site from Git"
3. Connect your GitHub repository
4. Build settings:
   - Build command: (leave empty)
   - Publish directory: `.`
5. Deploy!

## ✨ Features
- Real-time crypto data from CoinGecko API
- AI-powered token analysis via OpenAI
- Auto-scrolling trending tokens
- PDF report generation
- Stripe payment integration
- Beautiful animated UI

## 🛠 Tech Stack
- React (CDN)
- Tailwind CSS
- OpenAI API
- Stripe Payments
- jsPDF
- CoinGecko API
