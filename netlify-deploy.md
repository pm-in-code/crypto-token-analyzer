# 🚀 Альтернативный деплой на Netlify

## ⚡ **Быстрый деплой (альтернатива GitHub Pages)**

Если GitHub Pages работает медленно, можно использовать Netlify:

## 🔧 **Шаги для Netlify:**

### **1. Перейдите на Netlify:**
- Откройте: https://netlify.com
- Нажмите **"Sign up"** (можно через GitHub)

### **2. Подключите репозиторий:**
- Нажмите **"New site from Git"**
- Выберите **"GitHub"**
- Найдите репозиторий: `pm-in-code/crypto-token-analyzer`

### **3. Настройте деплой:**
- **Base directory**: оставьте пустым
- **Build command**: оставьте пустым
- **Publish directory**: `public`
- Нажмите **"Deploy site"**

### **4. Получите URL:**
- Netlify даст вам URL вида: `https://random-name.netlify.app`
- Можно настроить кастомный домен

## 🎯 **Преимущества Netlify:**
- ⚡ **Быстрый деплой** (30 секунд)
- 🔄 **Автоматические обновления** при push
- 🌐 **HTTPS по умолчанию**
- 📱 **Отличная производительность**

## 🔄 **Автоматический деплой:**
После настройки каждый push в main ветку будет автоматически деплоить сайт!
