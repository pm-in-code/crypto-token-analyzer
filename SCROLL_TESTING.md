# 🔄 Тестирование автоматического скроллинга

## 🧪 **Шаги для тестирования:**

### **1. Тестовый файл:**
- Откройте `test-scroll.html` в браузере
- Нажмите "Start Auto Scroll" 
- Проверьте, что элементы плавно двигаются слева направо

### **2. Основное приложение:**
- Откройте основное приложение
- Обновите страницу: `Cmd + Shift + R` (Mac) или `Ctrl + F5` (Windows)
- Дождитесь загрузки данных в блоке "Trending now"
- Проверьте автоматический скроллинг

### **3. Отладка в консоли:**
- Откройте Developer Tools (F12)
- Перейдите на вкладку Console
- Ищите сообщения:
  - "Starting auto-scroll with X tokens"
  - "Scroll debug: {...}"
  - "Reset scroll to beginning"

## 🔍 **Что проверять:**

### **✅ Работающий скроллинг:**
- Карточки плавно двигаются слева направо
- При достижении конца возвращаются к началу
- Скорость движения комфортная (не слишком быстро/медленно)

### **❌ Проблемы:**
- Карточки не двигаются
- Рывки или прерывания
- Слишком быстрый/медленный скроллинг
- Ошибки в консоли

## 🛠️ **Исправления:**

### **Если скроллинг не работает:**

1. **Проверьте консоль** на ошибки
2. **Убедитесь, что данные загрузились** (не показывается спиннер)
3. **Проверьте, что контейнер достаточно широкий** для скроллинга
4. **Попробуйте тестовый файл** для изоляции проблемы

### **Если скроллинг работает в тесте, но не в приложении:**

1. **Проверьте CSS классы** - убедитесь, что `auto-scroll-container` применяется
2. **Проверьте количество токенов** - должно быть больше 5 для эффекта
3. **Проверьте размеры контейнера** - должен быть шире содержимого

## 📊 **Ожидаемые значения в отладке:**

```javascript
// Пример правильных значений:
Scroll Width: 2400    // Общая ширина всех карточек
Client Width: 800     // Видимая ширина контейнера  
Max Scroll: 1600      // Максимальная позиция скролла
Current Scroll Left: 150  // Текущая позиция
Can Scroll: true      // Можно ли скроллить
```

## 🎯 **Параметры скроллинга:**

- **scrollStep**: 2px (шаг движения)
- **scrollSpeed**: 50ms (частота обновления)
- **Задержка старта**: 1000ms (для загрузки DOM)

## 🔧 **Возможные исправления:**

### **Если скроллинг слишком медленный:**
```javascript
const scrollStep = 3; // Увеличить шаг
const scrollSpeed = 30; // Уменьшить интервал
```

### **Если скроллинг слишком быстрый:**
```javascript
const scrollStep = 1; // Уменьшить шаг
const scrollSpeed = 80; // Увеличить интервал
```

### **Если скроллинг не начинается:**
- Увеличить задержку старта до 2000ms
- Добавить проверку `scrollContainer.offsetWidth > 0`
